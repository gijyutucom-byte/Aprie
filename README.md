# アプリエ（AI App Maker）

アプリエは、先生方が思い付いた教材アイデアをWebアプリの形にし、授業や校務等で活用することを支援するWebアプリです。生徒が身近な課題の解決に取り組む際にも活用できます。

公開ページ：<https://gijyutu.com/g-soft/ai_designer/>

## 主な機能

### ① アプリを作る

目的、利用者、機能、画面・操作、条件、参考資料を整理し、ChatGPT、Gemini等の生成AIへ渡す仕様書・依頼文を作成します。

- **Lite**：保存機能を使わないシンプルなアプリ向け
- **Plus**：保存するデータや保存方法も検討するアプリ向け
- **簡単設計**：機能と条件を箇条書きで入力
- **詳細設計**：機能ごとに条件を対応付けて入力

### ② アプリを動かす

アプリがうまく動かないときに、症状、再現する操作、期待する動作、試したことを整理し、AIへ修正を依頼する文章を作成します。

### ③ アプリを理解する

仕様とソースコードをもとに、要件定義書とPlantUML形式のアクティビティ図を作成するための依頼文を生成します。完成したアプリをブラックボックス化せず、処理の流れを確認・説明するために活用します。

## 仕組み

アプリエはブラウザ上で動作し、利用者の入力を整理して生成AIに渡すためのプロンプトを作ります。外部AIへの自動送信やコードの自動実行は行いません。

GIGAスクール端末での利用を想定し、文字の大きさ、タップしやすい操作領域、一般的なブラウザでの動作などもAIへの依頼に含められます。生成AIには、HTML・CSS・JavaScriptを原則として一つのHTMLファイルにまとめたWebアプリとして出力するよう促します。ただし、外部ライブラリ、保存機能、外部サービス連携を用いる場合は、別ファイルや追加設定が必要になることがあります。

## 使い方

1. 作りたい教材・校務用アプリのアイデアを決めます。
2. 「① アプリを作る」で、目的・利用者・機能・条件を整理します。
3. 生成された依頼文をコピーし、学校で認められた生成AIに貼り付けます。
4. 作成されたHTMLファイルを保存し、動作を確かめます。
5. 必要に応じて「② アプリを動かす」で改善します。
6. 「③ アプリを理解する」で、仕様・コード・処理の流れを確認します。

## 活用の考え方

まずは先生方自身が、小さな教材・校務用アプリを一つ試作することをおすすめします。例として、授業導入の三択クイズ、振り返りチェックリスト、グループ分けルーレット、防災・地域学習用の情報提示アプリなどがあります。

生成AIとの対話で試作を繰り返す「バイブコーディング」は、単にAIに作らせる活動ではありません。課題を見いだし、設計し、試し、改善し、仕組みを説明する活動として位置付けます。

Gemini Canvas等と組み合わせる場合は、**アプリエで考える・直す・理解する**ことを支え、**Gemini Canvasで素早く作る・試す・編集する**という使い分けができます。

## 生徒に使用させる場合

生徒にいきなり使わせるのではなく、ビジュアルプログラミング等で、順次処理、分岐、繰り返し、変数、イベント、入出力、試行・修正といった基礎を学んだ後に扱うことをおすすめします。

利用前に、自治体、教育委員会、学校が定める生成AI利用ガイドライン、情報セキュリティ規程、端末利用のルールを必ず確認してください。利用できるAIサービス・アカウント、入力してよい情報、成果物の公開範囲、著作権の扱いは、各学校の方針に従います。

完成物だけでなく、課題設定、仕様、試作・改善の過程、処理の仕組みを説明できることを重視します。

## 作成したアプリの活用・共有

| 方法 | 主な用途 | 留意点 |
| --- | --- | --- |
| ローカルファイルとして開く | 試作・動作確認 | 外部ライブラリ等によっては動作しないことがあります。iPadではローカルHTMLをブラウザで実行しにくい場合があります。 |
| Gemini、Canva等の共有機能 | 授業内・校内での共有 | 学校の利用許可、共有範囲、アカウントの扱いを確認します。 |
| Google Sitesへの掲載 | 学級・学校内での紹介 | 共有設定と公開範囲を確認し、個人情報を掲載しません。 |
| GitHubでの公開 | 継続的な更新・本格的な公開 | 公開範囲、ライセンス、著作権、個人情報、管理体制を確認します。 |

## 注意事項

- AIが生成するコードや説明は、必ずしも正確ではありません。内容・動作・安全性を確認してください。
- 氏名、学籍番号、メールアドレス、パスワード、APIキーなどの重要な情報をAIに入力しないでください。
- PlantUML図の表示には、ネットワーク接続と外部サービスが必要になる場合があります。
